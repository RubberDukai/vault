The offline knowledge vault

Setting up Vault

Two ways to put Vault on a machine: a small installer to send to friends, and a full copy on a USB stick that runs anywhere with no internet at all. This covers both, start to finish.

Which one do you need

Send it

The installer

One 34 MB file, VaultSetup.exe. Email it, or share a link.

  • Best for friends with internet
  • Installs the app in seconds
  • They pick and download the encyclopedias, maps and books afterwards, from inside Vault
Carry it

The USB master

A complete Vault on a stick — around 55 GB with everything loaded.

  • Needs no internet, ever
  • Runs straight off the stick, or copied onto any Windows PC
  • Already holds every pack, map, book and the program itself

Part 1 · The installer

Give a friend the file VaultSetup.exe. On their computer:

  1. Double-click VaultSetup.exe. Windows will say “Windows protected your PC” — that is normal for a program without a paid signing certificate, not a warning that anything is wrong.

  2. Click “More info”, then “Run anyway”. It installs just for that user, into their own account — no administrator password needed.

  3. Open Vault. A shortcut is added to the Desktop and Start Menu. The first launch opens a black window and then the Vault itself in a browser.

  4. Choose what to load. Go to Setup → Get packs and tick what you want — Simple English Wikipedia, the survival handbook already ships, maps, textbooks. Each downloads in the background. This is the one step that needs a connection.

No installer, no fuss. If a friend’s machine blocks the .exe outright, send Vault-1.0.0-portable.zip instead. They unzip it anywhere and double-click Vault.bat — same program, nothing installed.

Part 2 · The USB master

This is the copy that needs nothing — no internet, no install. You build it once from your own loaded Vault, then it runs on any Windows PC.

Build it onto the stick

Plug in the USB stick and note its drive letter (say E:). Open a command window in your Vault folder and run one line:

rem  copies the program, packs, maps, books and Node onto the stick
node tools/make-portable.js E:/Vault --with-packs --with-maps --with-docs --with-node

It writes a self-contained Vault folder to the stick and skips anything half-downloaded. Around 55 GB, so give it time. A START HERE.txt is written alongside it for whoever picks up the stick.

Run it from the stick

  1. Plug the stick into any Windows computer.

  2. Open the Vault folder on the drive.

  3. Double-click Vault.bat. It carries its own copy of Node, so nothing has to be installed — the black window opens and Vault appears in the browser.

Copy it onto a machine

Running off a stick works, but a fixed disk is faster and frees the stick. To leave a permanent copy on a computer:

  1. Copy the whole Vault folder from the stick to somewhere on the computer — the Desktop or Documents is fine.

  2. Open the copied folder and run Vault.bat. That machine now has its own Vault and no longer needs the stick.

Keep the stick as the master. Copy from it onto machines; do your own reading, note-taking and downloading in a copy on a disk. That way the stick stays a clean, complete original you can hand to the next person.

Every time you open it

  • Leave the black window open. That window is Vault running — close it and Vault switches off. Minimise it instead.
  • Read it on a phone or tablet. The black window prints two or three web addresses. On a device on the same wi-fi, type the second address into any browser — nothing to install on the phone.
  • If it says Node.js is missing: a copy with a node folder (the installer and the USB master both have one) needs nothing. Otherwise install the LTS version from nodejs.org, accept the defaults, and open Vault again.

Locking it (optional)

If the machine might be picked up by someone else, set a PIN under Setup → Privacy. It encrypts everything the household writes — notes, spreadsheets, the calendar, map markings, messages — so a lost or stolen disk gives nothing up. The encyclopedias and maps are left as they are; they are public knowledge and tell no one anything about you.

Write down the twelve-word recovery phrase. It is shown once, when you set the PIN, and it is the only way back in if the PIN is forgotten. Put it on paper, away from the machine.
